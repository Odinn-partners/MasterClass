# 🏆 Golden Prompts C-Level

**La bibliothèque de prompts du livre *PME & ETI - Guide de Survie Data & IA - Le Modèle Centaure*, de Cédric Jacques et Mathieu Treillard (Odinn Partners).**

Vous avez lu l'histoire de Jean-Pierre et d'ACME Industries. Voici les outils pour l'appliquer dès lundi dans votre Comex.

Une IA ne connaît ni votre entreprise, ni vos priorités, ni votre bon sens managérial. Une question vague donne une réponse vague.
Un **Golden Prompt** fonctionne comme une fiche de poste : il fixe le cadre, les sources autorisées et la posture attendue, pour obtenir une réponse directement exploitable par un dirigeant.

---

## 🧭 La méthode C.A.D.R.E.

Chaque prompt de cette bibliothèque suit la même structure :

| Lettre | Élément | La question à se poser |
|---|---|---|
| **C** | Contexte | Qui sommes-nous, quelle est la situation, quel problème résoudre ? |
| **A** | Action | Que demandons-nous précisément à l'IA ? |
| **D** | Données | Sur quelles sources vérifiables doit-elle *exclusivement* s'appuyer ? |
| **R** | Rôle | Quelle expertise et quel niveau d'exigence doit-elle adopter ? |
| **E** | Évaluation | Sous quel format et selon quels critères jugerons-nous le résultat ? |

## 🚀 Comment les utiliser

1. **Copiez** le prompt correspondant à votre besoin.
2. **Adaptez** le Contexte et les Données à votre situation réelle (les exemples reprennent le cas ACME du livre).
3. **Ajoutez** le Master Prompt si l'enjeu est sensible.
4. **Exécutez-le** dans l'IA d'entreprise de votre organisation.
5. **Validez** : l'IA propose, le dirigeant décide.

---

## ⚠️ Avant de commencer

> **Ne soumettez jamais de données confidentielles à une IA publique ou gratuite.**
> Si l'outil est gratuit, votre propriété intellectuelle est le produit.

Ces prompts sont conçus pour être utilisés dans un environnement sécurisé de type **Walled Garden** (IA d'entreprise, idéalement hébergée sur un cloud souverain). Ils ne remplacent ni le jugement des dirigeants, ni la validation des données, ni la responsabilité humaine attachée à la décision.
