**1. LE PROMPT "FINANCE"**

**Objectif : identifier les économies OPEX accessibles sans réduire la capacité de production.**

\[C\] Contexte

Nous répondons à un appel d’offres de 2 M€ pour notre client historique, « Müller ».

Notre offre est 15% plus chère que celle d’un concurrent asiatique. Elle présente toutefois plusieurs avantages opérationnels :

- notre délai de livraison est de quatre semaines contre douze pour le concurrent ;

- notre taux de panne est proche de zéro ;

- une défaillance ou un retard pourrait provoquer chez Müller des arrêts de chaîne de production coûteux.

Nous devons donc réduire les dépenses non nécessaires sans affaiblir la qualité, les délais, la fiabilité ou la continuité de production.

\[A\] Action

Analyse les dépenses d’exploitation afin d’identifier les trois lignes budgétaires ou catégories présentant le plus fort potentiel d’économie.

Pour chacune d’elles :

1.  compare les dépenses de l’année en cours avec celles de l’année précédente, lorsque les données le permettent ;

2.  repère les hausses inhabituelles, les dépenses récurrentes, les doublons et les montants exceptionnellement élevés ;

3.  distingue une dépense élevée d’une dépense effectivement inutile ou rationalisable ;

4.  estime le montant économisable ;

5.  évalue le risque potentiel pour la production, la qualité, les délais, la sécurité et la relation client ;

6.  propose une action immédiate, réversible et mesurable.

Ne présente pas une hypothèse comme un fait. Si le potentiel d’économie ne peut pas être calculé de manière fiable, indique « Non déterminable » et explique pourquoi.

\[D\] Données

Base-toi exclusivement sur les fichiers fournis :

- « Grand_Livre_Q3.csv » ;

- le fichier des dépenses fournisseurs ;

- toute donnée complémentaire explicitement jointe à cette demande.

Avant toute analyse :

1.  vérifie la structure des fichiers, les périodes, les devises et les unités ;

2.  identifie les colonnes manquantes, les doublons, les valeurs nulles et les incohérences ;

3.  vérifie que la comparaison avec l’année précédente est possible ;

4.  signale toute limite susceptible d’affecter la fiabilité du résultat.

N’utilise aucune norme externe, aucun prix de marché et aucun objectif d’économie qui ne figurerait pas dans les documents fournis. N’invente aucun chiffre.

\[R\] Rôle

Agis comme un directeur du contrôle de gestion spécialisé dans la restructuration financière des ETI industrielles.

Tu combines :

- une grande rigueur analytique ;

- une bonne compréhension des opérations industrielles ;

- une attention particulière à la continuité de production ;

- une capacité à distinguer les économies durables des réductions de coûts dangereuses ;

- une exigence de traçabilité des calculs et des hypothèses.

\[E\] Évaluation

Commence par un résumé exécutif de quatre lignes maximum, sans jargon.

Présente ensuite un tableau comportant exactement les colonnes suivantes :

| **Catégorie de dépense** | **Montant économisable estimé (€)** | **Risque opérationnel** | **Action immédiate** |
|----|----|----|----|

Le risque doit être qualifié de « Faible », « Moyen » ou « Fort ».

Après le tableau, ajoute une section intitulée **« Justification des calculs »**. Pour chaque ligne, précise :

- les chiffres sources ;

- la formule utilisée ;

- les hypothèses éventuelles ;

- le niveau de confiance : Élevé, Moyen ou Faible.

Termine par une section intitulée **« Données manquantes ou limites »**, si nécessaire.
