**LE PROMPT "PRODUCTION"**

**Objectif : identifier la cause probable d’une hausse anormale des rebuts.**

\[C\] Contexte

Sur notre ligne de presses hydrauliques n° 4, le taux de rebut est passé de 2% à 5% en deux semaines.

Cette dérive affecte directement la marge brute journalière. Les équipes terrain n’ont pas encore identifié l’origine de l’anomalie.

Nous souhaitons rechercher une relation temporelle entre :

- les paramètres de maintenance et de fonctionnement ;

- la température ;

- la pression ;

- les interventions techniques ;

- les changements de lots de matières premières ;

- les fournisseurs ;

- les équipes ;

- les références produites ;

- la cadence et les conditions de production ;

- les types de défauts observés.

\[A\] Action

Croise les relevés de maintenance et de fonctionnement de la ligne n° 4 avec le suivi des lots de matières premières.

1.  Décris l’évolution du taux de rebut avant et après l’apparition de l’anomalie.

2.  Identifie les événements intervenus au même moment que la hausse des rebuts.

3.  Compare les périodes, lots, fournisseurs et conditions de production lorsque cela est possible.

4.  Sélectionne au maximum trois causes candidates.

5.  Pour chaque cause, précise :

    - les faits observés ;

    - les données qui la soutiennent ;

    - les données qui la fragilisent ;

    - le nombre d’observations concernées ;

    - les facteurs confondants possibles ;

    - le niveau de confiance.

6.  Distingue toujours corrélation et causalité.

Ne fournis pas de pourcentage de probabilité mathématique si aucun modèle statistique approprié ne le justifie.

Si tu calcules un score probabiliste, précise :

- la méthode utilisée ;

- les variables prises en compte ;

- les hypothèses ;

- la taille de l’échantillon ;

- les limites d’interprétation.

Pour chaque cause prioritaire, propose un « Quick Win » testable dès demain matin.

\[D\] Données

Analyse les fichiers suivants :

- « Maintenance_Ligne4.xlsx » ;

- « Lots_Acier_Septembre.csv » ;

- tout fichier de production ou de qualité joint à la demande.

Avant toute conclusion :

1.  contrôle les dates et les heures ;

2.  harmonise les identifiants de machine, de lot, de fournisseur et de période ;

3.  vérifie les doublons, les trous de données et les valeurs aberrantes ;

4.  vérifie que les événements peuvent être correctement alignés dans le temps ;

5.  indique si les données permettent d’établir une causalité ou seulement une association.

N’invente aucune observation, aucune mesure et aucune cause non étayée.

\[R\] Rôle

Agis comme un expert Lean Six Sigma Black Belt spécialisé dans :

- l’analyse des défauts industriels ;

- la maîtrise statistique des procédés ;

- l’analyse des causes racines ;

- la maintenance préventive et corrective ;

- l’expérimentation terrain ;

- l’amélioration continue de la performance industrielle.

Adopte une posture rigoureuse, prudente et orientée vers des actions concrètes.

\[E\] Évaluation

Commence par un diagnostic de cinq lignes maximum.

Présente ensuite un tableau comportant les colonnes suivantes :

| **Rang** | **Cause candidate** | **Éléments probants** | **Éléments contradictoires** | **Niveau de confiance** | **Quick Win** |
|----|----|----|----|----|----|

Ajoute ensuite les sections suivantes :

Méthode d’analyse

Explique brièvement les rapprochements, comparaisons et calculs effectués.

Limites et données manquantes

Indique les éléments susceptibles de réduire la fiabilité du diagnostic.

Plan de vérification à 24 heures

Pour chaque action, précise :

- l’hypothèse testée ;

- la modification à effectuer ;

- le périmètre du test ;

- la durée ;

- les indicateurs à suivre ;

- le seuil de réussite ;

- le critère d’arrêt ;

- la personne responsable de la validation.

Aucune modification irréversible d’un paramètre critique ne doit être recommandée sans validation du responsable production, qualité ou maintenance.
